# Sito di HomeManager

Sito minimo per l'App Store: home, informativa sulla privacy e supporto, in italiano e inglese.

## Prima di pubblicare

Sostituisci `TUA-EMAIL@esempio.com` con il tuo indirizzo email in `privacy.html` e `support.html`.

## Pubblicarlo con GitHub Pages

1. Su GitHub crea un repository **pubblico**, per esempio `homemanager`.
2. *Add file → Upload files*: trascina tutti i file di questa cartella e conferma con *Commit changes*.
3. *Settings → Pages*: in *Source* scegli *Deploy from a branch*, poi il branch `main` e la cartella `/ (root)`, e premi *Save*.
4. Dopo un paio di minuti il sito è online su `https://TUO-UTENTE.github.io/homemanager/`.

## Cosa inserire in App Store Connect

| Campo | Indirizzo |
| --- | --- |
| URL della politica sulla privacy | `https://TUO-UTENTE.github.io/homemanager/privacy.html` |
| URL di supporto | `https://TUO-UTENTE.github.io/homemanager/support.html` |
| URL di marketing (facoltativo) | `https://TUO-UTENTE.github.io/homemanager/` |

Per la scheda in inglese puoi aggiungere `#en` alla fine degli indirizzi.
